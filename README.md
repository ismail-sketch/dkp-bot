# 🚗 ДКП-бот — договор купли-продажи автомобиля в Telegram

Бот формирует комплект документов для сделки с автомобилем:

- **договор купли-продажи** — 3 экземпляра (продавцу, покупателю, для ГИБДД), каждый на отдельной странице;
- **акт приёма-передачи**;
- **расписка** в получении денежных средств.

Профиль (свои паспортные данные) заполняется один раз и подставляется в каждый договор.
Данные второй стороны и автомобиля вводятся по шагам с проверкой каждого поля.

## Быстрый старт

```powershell
# 1. Виртуальное окружение
python -m venv .venv
.\.venv\Scripts\activate

# 2. Зависимости
pip install -r requirements.txt

# 3. Токен бота
copy .env.example .env
notepad .env          # вписать BOT_TOKEN от @BotFather

# 4. Запуск
python run.py
```

Требуется только Python 3.11+. Ни Docker, ни сервер БД, ни LibreOffice не нужны.

## Проверка без Telegram

```powershell
python tools/selftest.py     # 60 проверок: сумма прописью, валидаторы, сборка сделки, PDF
python tools/preview_docs.py # образцы документов в data/preview/
```

## Как устроено

```
run.py                 точка входа, polling
config.py              настройки из .env, ключ шифрования
bot/
  handlers.py          меню, профиль, визард, архив
  wizard.py            универсальный пошаговый движок (декларативные поля)
  states.py            состояния FSM
  keyboards.py         клавиатуры
  services.py          сборка сделки, отправка, сохранение в архив
  db.py                модели SQLAlchemy
  crypto.py            шифрование паспортных данных (Fernet)
  utils/
    validators.py      проверка полей (VIN, паспорт, цена, даты)
    money.py           сумма прописью со склонениями
  docs/
    contract_form.py   договор по типовому одностраничному бланку (3 экз.)
    pdf_generator.py   акт приёма-передачи и расписка
tools/                 selftest, генератор образцов
assets/fonts/          DejaVu Sans и Liberation Sans (свободные лицензии)
```

**Ключевое архитектурное решение:** документы собираются сразу в PDF, минуя LibreOffice.
Поэтому проект запускается на любом ПК и переносится на VPS без системных зависимостей.

## Перенос на российский VPS

Код не меняется, только `.env`:

```ini
DATABASE_URL=postgresql+psycopg://dkp:password@localhost:5432/dkp
```

1. `apt install python3.11 postgresql`, создать БД.
2. Скопировать проект, `pip install -r requirements.txt`.
3. Заполнить `.env`, перенести данные из SQLite.
4. Автозапуск через `systemd` (`Restart=always`).
5. Бэкап: `pg_dump` по cron.

## Персональные данные

- Паспортные данные (ФИО, серия/номер, кем выдан, адрес) хранятся **зашифрованными** (Fernet, ключ в `data/secret.key` или `.env`, вне БД).
- Файлы документов **не сохраняются на диск** — генерируются в памяти и отправляются в Telegram; в архиве хранится `file_id`.
- `/delete_me` удаляет профиль, сделки и контрагентов.
- Сканы документов (этап OCR) не сохраняются — обрабатываются в памяти.

Перед публичным запуском: уведомление в Роскомнадзор как оператора ПДн, хостинг на территории РФ.

## Статус

Реализовано: профиль, визард сделки (вторая сторона → авто → условия), проверка данных
перед генерацией, редактирование любого блока, PDF-комплект, архив, удаление данных.

Не реализовано (по ТЗ, следующие этапы): OCR сканов, DOCX, тарифы и оплата, сохранённые контрагенты.
